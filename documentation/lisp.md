# Linux Show Player (LiSP)

The Linux Show Player is not part of this repository. It plays the project (`.lsp`) generated by the
[Cue Generator](cue-generator.md) during the show: it plays the audio effects and sends the OSC commands for the
Behringer X32 and the ChamSys MagicQ.

For installation, command line arguments and usage, refer to the official documentation:

- Website: https://www.linux-show-player.org/
- Documentation: https://linux-show-player-users.readthedocs.io/

The generated projects target LiSP version 0.6.5. Things to keep in mind when using them with this repository:

- The audio files (`<Audio Effect>.wav`) must be placed next to the `.lsp` file.
- LiSP sends all OSC cues to one global destination. Configure it to the host and port of the
  [OSC Relay](osc-relay.md) (LiSP's default, `localhost:9001`, matches the relay's default).
- The GO key (Space by default) can be pressed with the [Buzzer](buzzer.md) and the
  [Serial Keyboard](serial-keyboard.md).
